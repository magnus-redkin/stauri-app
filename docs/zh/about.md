## 什么是 Web3 即时通讯？

消息不经过公司服务器，而是通过点对点网络传递：没有谁能独占整段历史，也没有谁能删除或读取它。钱包就在同一个应用里，因为消息背后的身份就是持有资金的那把密钥。

- 服务器上没有账号：密钥对本身就是账号。
- 12 个词的助记词是资料和资金的同一把主密钥。
- 消息端到端加密；节点只转发，不读取。

## 什么是 Status 网络？

Status 是一组开源程序（Status 应用、status-go 引擎和 Waku 传输层）组成的同一个网络。节点通过启动列表（“fleet”）互相发现，并交换封装的讯息；聊天和钱包请求都走这张网。

- Waku 是传输层：存储并转发封装的信封。
- fleet 是起始节点列表；Status 提供公开的一个。
- status-go 是引擎；Stauri 以库的方式加载它，并绘制自己的界面。

## Stauri 与 Status.im

Stauri 与 Status Desktop 使用同一个引擎和同一张网络。区别有两处：技术栈和用词。

1. **用 Tauri + Svelte 取代 Nix + Nim/QML。** 界面是用 Svelte 写的网页前端：改动周期短，桌面和 Android 共用一份 Rust 代码，外部 dApp 在独立窗口中打开。Status Desktop 则是一个用 Nix 构建的 Nim 与 QML 单体。
2. **界面中没有“社区”概念；频道就是 ACC。** Status 的社区只是一个包含单一频道的技术容器。Stauri 隐藏容器，直接把频道（ACC）作为用户认识的实体显示。
