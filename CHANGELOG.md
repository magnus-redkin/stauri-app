# Changelog

Все заметные изменения Stauri. Секции генерирует `scripts/release-changelog.sh`
из Conventional Commits; новые версии идут сверху.

## [0.5.2] — 2026-11-23

### Добавлено
- Привязка ENS-имени, которым владеет кошелёк профиля: после восстановления
  из фразы имя не пропадает — экран ENS распознаёт его как своё и показывает
  кнопку «Attach to this profile» без транзакции и депозита.
- Строчка «Stauri v. <версия>» в профиле: видимая версия сборки и повторная
  проверка обновления по клику — фоновая проверка идёт раз в час.

### Исправлено
- Один способ входа на обеих платформах: введённое значение — это PIN (цифры
  на телефоне, пароль на десктопе), конверт создаётся молча после входа.
  Экран больше не спрашивает «создать PIN» после «пароля» — то же самое,
  дважды.
- Успешное восстановление из фразы открывает профиль и уходит с экрана
  восстановления: раньше сессия открывалась на стороне бэкенда, а интерфейс
  оставался на поле пароля.
- Падение узла после входа (`node.crashed`) превращается в сообщение вместо
  вечного зависания на старте мессенджера; «seed phrase not saved» не висит
  красным после успешного восстановления.
- Неверный пароль на экране восстановления больше не оставляет на том же поле:
  экран сам переходит к выбору «новая локальная копия», там же — вкладки
  «Existing profile / New local copy» и правило: старый пароль не проверяется
  по новым правилам, новые — по правилам платформы.
- «Save name settings» остаётся на профиле и говорит «Saved» — вместо перехода
  на Home, который читался как ошибка.
- Удаление локальной копии стирает её только если профиль действительно
  локальный.

### Изменено
- Дефолтное экранное имя нового профиля: «Stauri User» → «New stauri user».
## [0.5.1] — 2026-11-22

### Добавлено
- Английская документация стала основной: полные переводы всех документов в
  `docs/en/` (архитектура, Web3 IM, сравнение, авторизация и синхронизация,
  сети и балансы, провайдеры и dApp, схема АКК, тесты), ссылки в `README.md`
  ведут на английские версии.
- Экран «О Stauri»: у каждого раздела несколько ссылок — на внутренний документ
  и на внешний источник (Status, Waku, Logos, ENS). Внешние ссылки открываются
  в системном браузере, внутренние — в окне приложения.

### Изменено
- Файлы `about.md` всех четырёх языков переписаны: восемь коротких разделов без
  технических подробностей — Web3 IM, сеть Status, пароль и seed-фраза,
  Stauri против Status, патч status-go, ENS, синхронизация устройств, TODO/DONE.
- Создание профиля из уже открытой сессии сначала выполняет выход: иначе
  `waitForLogin` срабатывает по устаревшему флагу и следующий вход идёт под
  предыдущим профилем (`failed to open database`).
- На экране создания имени поле получает фокус с выделенным значением — одно
  нажатие Backspace очищает его целиком.

### Исправлено
- Неверно введённый PIN очищается после отказа: следующие нажатия начинают новый
  ввод, а не дописываются к уже введённому.
- Во время создания профиля PIN-пад показывает индикатор работы вместо пустого
  места: хеширование пароля и старт узла занимают секунды.

## [0.5.0] — 2026-11-21

### Добавлено
- Синхронизация через локальную сеть: два устройства находят друг друга
  автоматически, шесть цифр на двух экранах подтверждают, что речь об одном и
  том же соединении, передача идёт по шифрованному каналу. USB-кабель — запасной
  путь, когда Wi-Fi недоступен.
- Профиль на экране входа: список профилей с экранными именами и выбор, к
  мастеру создания (PIN → seed-фраза → имя, всё кроме PIN пропускается).
- Раздельные сборки Android: релизная (Stauri, mainnet) и dev (Stauri.dev,
  Sepolia, отдельный package id) ставятся рядом; `reset-test-clients.sh SA`
  чистит только dev, релизный профиль с реальными средствами и ENS недоступен
  скрипту.

### Изменено
- PIN: на телефоне 5–12 цифр, тривиальные последовательности отклоняются; на
  десктопе 8–64 символа четырёх классов. Проверка сложности — только при
  создании, открытию поддаётся любой сохранённый PIN.
- Блокировка на десктопе при сворачивании в трей/минимизацию, а не при
  переключении между окнами.
- Синхронизация теперь двушаговая: профиль передаётся только после нажатия
  Sync на обоих устройствах.

### Исправлено
- Имя профиля в списке теперь обновляется после смены.
- Ошибки pairing с реальной причиной, а не общим «pairing failed».
## [0.4.1] — 2026-11-15

### Изменено
- Строгие правила пароля при создании профиля и при входе: не менее 8 символов,
  заглавная и строчная латинские буквы, цифра и символ. Поле подтверждения при
  создании профиля. Профили с более слабым паролем перестают открываться — это
  осознанное требование, а не регрессия.
- Комментарии в исходниках переведены на английский и приведены к стандартному
  виду (`docs/COMMENT_STYLE.md`): модули и функции документированы по правилам
  Rust, TypeScript и shell.

### Добавлено
- Чистое окружение для проверки релиза: `scripts/clean-env.sh` и переменные
  `STAURI_DATA_DIR` / `STAURI_CONFIG_DIR` запускают сборку с отдельным профилем,
  не затрагивая рабочий.

## [0.4.0] — 2026-11-15

Стабильный выпуск. Код совпадает с `0.4.0-beta` (тег `v0.4.0-beta`), отличается
только версия. Выпуск нужен, чтобы проверить автообновление: установленная
beta должна получить 0.4.0 через `releases/latest`, который не отдаёт prerelease.
